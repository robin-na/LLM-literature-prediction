# Results Layout

Analysis outputs are now organized into subfolders that mirror the `plots/` layout for the main validation workflows.

Current structure:

- `validation/no_augmentation_model_comparison/`
  Baseline model-comparison tables for the validation wave, including first-run vs repeat-averaged baseline comparisons.

- `validation/augmentation_delta_by_model/`
  Validation augmentation delta tables corresponding to the heatmap figures.

- `validation/augmentation_convergence/`
  Convergence summaries, spread tables, and sampling-robustness checks for augmentation analyses.

- `validation/model_suite_comprehensive/`
  Nine-model validation suite summaries, baselines, augmentation rows, and spread summaries.

- `validation/reasoning_repeat_summary/`
  Repeated-sampling summaries, repeat-vs-temp0 comparisons, heterogeneity tables, and ensemble analyses.

- `validation/paper_only_41family/`
  Focused comparison for `GPT-4.1`, `GPT-4.1 Mini`, and `GPT-4.1 Nano` on the three `paper_only` report formats, covering:
  - direct `single w/o explanation` performance plus logprob-derived uncertainty
  - `single with explanation` and `joint with explanation` performance plus 5-run prediction variance
  Generated by `python analysis/analyze_validation_paper_only_41family.py`.

- `validation/positive_case/literature_design_space/`
  Canonical location for the current positive-case analysis that defines the design space to carry into the published-paper augmentation study.
  Covers the four performance metrics (`RMSE`, `R^2`, `Directional Accuracy`, `Correlation`), baseline-vs-augmentation deltas, convergence summaries, dumbbell comparisons, paired-bootstrap correlation significance checks, and random-effects meta-analytic summaries.
  Generated by `python analysis/positive_case/literature_design_space/plot_validation_paper_only_narrative_decision.py` and `python analysis/positive_case/literature_design_space/analyze_validation_paper_only_narrative_decision_meta.py`.

- `validation/paper_only_narrative_decision/`
  Legacy location for the same analysis family before the reorganization into `validation/positive_case/literature_design_space/`.

Legacy outputs that have not yet been migrated remain at the `results/` root or in their existing nested folders.
