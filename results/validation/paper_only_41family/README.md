# Paper-Only 4.1 Family

Focused comparison for `GPT-4.1`, `GPT-4.1 Mini`, and `GPT-4.1 Nano` on the three `paper_only` report formats:

- `paper_only_freeform`
- `paper_only_quantitative`
- `paper_only_structured`

Generated by:

```bash
python analysis/analyze_validation_paper_only_41family.py
```

Files:

- `validation_paper_only_41family_direct.csv`
  Direct `single w/o explanation` comparison.
  Performance is taken from the validation model-suite results.
  Uncertainty is measured from token logprobs as:
  - mean chosen-token perplexity
  - mean top-1 probability
  - mean truncated top-k perplexity

- `validation_paper_only_41family_explained.csv`
  `single with explanation` and `joint with explanation` comparison.
  Performance is measured on the predictor formed by averaging the 5 temperature-1 runs.
  Variance is measured as the mean question-level SD across the 5 runs.

- `validation_paper_only_41family_combined.csv`
  Unified long-form table combining the direct and explanation-included comparisons with matched baseline deltas.
